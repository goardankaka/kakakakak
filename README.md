# Desert Ops Android prototype

Standalone Android FPS-style prototype (Kotlin/Canvas), not connected to Standoff 2.

## Included
- Main menu and map selection
- Match screen with a 20-second warm-up countdown
- In-match settings menu
- Local demo toggles for WH, aim assist, spin, anti-aim, and trigger-bot behavior
- Three cosmetic color skins
- Simple bot targets, shots, kills, and rounds

These are prototype-only visual/gameplay demonstrations. There is no Standoff 2 integration, no real 3D engine, no online multiplayer, and no external-game cheat functionality.

## Build APK
1. Install Android Studio.
2. Extract the ZIP and open the `DesertOpsAndroid` folder.
3. Wait for Gradle Sync; install Android SDK Platform 35 if requested.
4. Choose **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Locate `app/build/outputs/apk/debug/app-debug.apk`.
6. Transfer the APK to your Android phone and install it only if you trust the source.
